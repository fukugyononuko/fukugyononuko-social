## RCA
### P-01・P-02：プロジェクトの外の実行環境を意識していなかった
- なぜ 1：hook は macOS の python3、定期実行は launchd から動く。どちらも、開発とテストで使う環境（uv の Python 3.14、`uv run` の PATH）とは違う。
- なぜ 2：道具（ruff、`uv run`）は、プロジェクトの環境を前提に動く。
- 根本原因：「どの環境で動くか」を、ファイルごとに決めて検査する観点がなかった。
- 再発防止策：詳細設計のチェックリストに、プロジェクトの外の環境で動くファイルの、版と場所の固定と検査を加える。

### P-03：フェーズの終わりに、ルートの README を見ていなかった
- 根本原因：フェーズの終わりの手順（決まり 5）が、vault のノートだけを対象にしていた。
- 再発防止策：決まり 5 に、ルートの README の状態も加える。
